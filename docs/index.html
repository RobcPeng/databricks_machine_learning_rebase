Repository & purpose

Machine-learning homework, rebuilt as real benchmark harnesses.

This repository holds two Databricks Asset Bundles. Each takes one machine-learning task, trains a grid of models on it, and rolls every run into a single gold leaderboard. Deploy the bundle, run one job, read the comparison table, and choose a model because the numbers said so.

Why I built this

Homework I wanted to do properly

I built this to redo my machine-learning homework the way I wish I had the first time, and to do it on Databricks.

The assignments were the classics. Detect objects and trace body pose in images. Use PCA and ICA to cut a wide dataset down to the few factors that carry the signal. The first time through, they were notebooks that ran once and went stale.

So I rebuilt each one as its own Asset Bundle, with a medallion data flow, MLflow tracking every run, and one gold leaderboard that says which model actually won. Two assignments became two small, honest benchmark harnesses you can deploy, run, and read. Where a real run has not happened yet, the site says so rather than showing a made-up number.

Purpose, summarized

What it is for, and who it is for

This is an education and developer-advocacy resource, not a product. It teaches a pattern: how to benchmark a family of models fairly, track every run, and govern the winner, twice over, on real public data.

for

Data scientists & ML engineers

A reference for benchmarking model families and registering the winner, on serverless compute.

for

Developer advocates & SAs

Two demo-ready bundles that show the Databricks pattern end to end, with real data and honest results.

for

Analysts & students

A grounded walk-through of what the detectors, pose models, reducers, and classifiers do.

The shape

Same three moves, both times

The two bundles share no code. Each has its own databricks.yml, package, and job. What they share is a rhythm.

01

Deploy the bundle

One command stands up the schema, volume, pipeline, and job under the uplevel catalog.

02

Run one job

A single job fans out across the model grid on serverless compute, GPU for vision and CPU for the classic sweep, and logs each run to MLflow.

03

Read the gold leaderboard

The last task writes a comparison table to the gold schema. One row per model, the metrics side by side.
