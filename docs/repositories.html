Two bundles, two walkthroughs.

Each folder in the repository is a self-contained Databricks Asset Bundle with its own databricks.yml, package, and job. Pick one and follow it from an empty catalog to a working leaderboard. Both share the catalog rpeng_upleveling and the same deploy, run, read rhythm.

obj_recg · uplevels_cv · serverless GPU

Computer vision

Object detection, 2D and 3D pose on sports video, then team and athlete performance from the CV features. Benchmarks six model families across nine specs, parameterized by sport.

Walks through: deploy · stage data · medallion pipeline · the model zoo · run the job · read the leaderboard · register and extend.

pca_ica · dr_bench · serverless CPU + local

Dimensionality reduction

Binary prediction of above-median outcomes across four public datasets, measuring whether PCA, ICA, random projection, and clustering help six classic classifiers. Runs on Databricks and off-platform.

Walks through: deploy · land the data · the reduce-cluster-model pipeline · reducers · classifiers · the 192-cell grid · reading outcomes from the factors.
