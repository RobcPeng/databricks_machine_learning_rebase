Data flow (medallion)

00 landing

dimensionality_reduction_00_landing

Download each public source; write verbatim rows to a per-dataset Delta table (nscg_2023, scorecard_2026, acs_co_2024, pisa_2022).

→
01 cleansed

dimensionality_reduction_01_cleansed

Apply row filters; derive binary label via median split on the target column; retain the spec feature set. One table per dataset.

→
02 curated

dimensionality_reduction_02_curated

Write leaderboard (one row per grid cell) and model_comparison (best test_roc_auc per dataset, model, reducer).

Known issue

The scorecard_2026 source currently fails to land: serverless egress cannot reach its download host. The bronze step skips any failed source and continues with the remaining datasets. Tracked on the kanban board.

The per-cell pipeline

Every grid cell runs one sklearn Pipeline with four stages in sequence.

A preprocess

ColumnTransformer

Numeric: SimpleImputer (median) then StandardScaler. Categorical: SimpleImputer (most_frequent) then OneHotEncoder (handle_unknown=ignore, max_categories=50).

→
B reduce

DimReducer

Wraps PCA, FastICA, or GaussianRandomProjection; passthrough when reducer=none. Default n_components=10.

→
C cluster features

ClusterFeaturizer

KMeans k=4 or GMM appends one-hot cluster-membership columns. Passthrough when clustering=none.

→
D model

Classifier

One of the registered classifiers: logistic_regression, svm_rbf, knn, random_forest, xgboost, or mlp (default sweep).
