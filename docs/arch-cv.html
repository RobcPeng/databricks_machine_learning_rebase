Model dispatch and registry

→

→

write_comparison()

All metrics written to gold.model_comparison, one row per spec.

→
registry

UC register + @prod

Best model per family registered in Unity Catalog; @prod alias set.

Sibling registries

SportSpec (_SPORTS in sports.py): detection classes, signature events, and biomechanics angles per sport. Six sports; golf is the default. PredictionTarget (_TARGETS in team_performance.py): XGBoost target definitions; 7 targets. Each registry is a Python dict; adding one entry enables a new sport or prediction target end to end.
